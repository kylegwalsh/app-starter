# Docs

This app is the optional documentation site, served at `docs.` while the web app lives at `app.`. It's built with [Fumadocs](https://fumadocs.dev/docs), so adding a page is as simple as dropping an MDX file into `content/docs`.

## Overview

- Next.js + Fumadocs, deployed with OpenNext
- MDX content with typed frontmatter
- Built-in search (Orama, indexed from the content)
- A simple landing page that links into the docs

## Directory Structure

```text
apps/docs/
├── app/                      # Next.js routes (App Router)
│   ├── layout.tsx            # Root layout
│   ├── layout.config.tsx     # Shared nav/links config for all layouts
│   ├── global.css            # Global styles
│   ├── (home)/               # Landing page
│   ├── docs/                 # Docs layout + catch-all page renderer
│   └── api/search/route.ts   # Search index
├── content/docs/             # MDX pages (the docs content lives here)
├── lib/source.ts             # Fumadocs loader (maps content to URLs under /docs)
├── source.config.ts          # Collections + frontmatter/meta schemas
├── mdx-components.tsx        # Components available inside MDX
├── next.config.ts            # Next.js config
├── AGENTS.md                 # Guidance for working on the site with AI
└── package.json
```

`.source/` is generated by `fumadocs-mdx` on install. Don't edit or commit it.

## Enabling

The site is optional and disabled by default. `bun run init` asks whether you want it and enables it for you. To enable it by hand, uncomment the docs import in `sst.config.ts`:

```ts
await import('./infra/docs');
```

When a domain is configured, the site is served at `docs.<domain>`.

## Running Locally

Once enabled, SST starts the docs site along with everything else. From the repo root:

```sh
bun dev
```

You can also run it on its own (on port 3002) without enabling it:

```sh
bun docs dev
```

## Deploying

Once enabled, it deploys with everything else. From the repo root:

```sh
bun run deploy
```

## Writing Docs

- Add `.mdx` files to `content/docs`. Each file becomes a page under `/docs` (e.g. `content/docs/setup.mdx` → `/docs/setup`).
- Use a `meta.json` in a folder to control page order and section titles.
- Customize the frontmatter schema in `source.config.ts`, and make extra components available to MDX in `mdx-components.tsx`.
- Update the nav title and links in `app/layout.config.tsx`.

See the [Fumadocs docs](https://fumadocs.dev/docs) for everything else.
