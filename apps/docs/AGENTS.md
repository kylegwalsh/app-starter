# Docs Guidelines

## Stack

Next.js (TypeScript), [Fumadocs](https://fumadocs.dev/docs), MDX, Tailwind CSS v4

## Directory Layout

```text
content/docs/      MDX pages (the docs content lives here)
app/(home)/        Landing page
app/docs/          Docs layout + catch-all page renderer
app/api/search/    Static search index (Orama, built from the source)
app/layout.config.tsx  Shared nav/links config for all layouts
lib/source.ts      Fumadocs loader (maps content to URLs under /docs)
source.config.ts   Collections + frontmatter/meta schemas
mdx-components.tsx Components available inside MDX
.source/           Generated by fumadocs-mdx (do not edit or commit)
```

## Commands

- `bun docs dev`: Start the docs dev server on port 3002 (can be added to `bun dev` by uncommenting line in `sst.config.ts`).

## Deployment

- Deployed via SST (`infra/docs.ts`) with OpenNext. It's optional and disabled by default (uncomment `infra/docs` in `sst.config.ts` to deploy it).
